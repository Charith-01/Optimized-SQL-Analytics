# Optimized SQL Analytics Project

## Overview

The objective is to design optimized SQL queries and analytical reports
using relational database concepts and advanced SQL features.

## Main Requirements

- Design relational database tables
- Use SQL joins
- Use Common Table Expressions
- Use window functions
- Optimize query performance
- Produce analytical reports

## Technologies

- MySQL 8.0
- MySQL Workbench
- Python
- pandas
- Microsoft Excel
- Visual Studio Code
- Git and GitHub
- Microsoft Word

## Project Structure

- `data/raw/` – Original dataset
- `data/processed/` – Cleaned and transformed datasets
- `python/` – Python data-preparation scripts
- `sql/` – Database and analytical SQL scripts
- `diagrams/` – Database diagrams
- `screenshots/` – Query results and execution plans
- `report/` – Final analytical report

## Deliverables

- SQL scripts
- Query performance analysis
- Analytical report
